WYRMWAKE — a sea-monster hunting game. A lone ninja faces the golden King Wyrm and the 13 monsters of three black seas. Fights are chain-harpoon stamina duels: throw the harpoon by hand, strike glowing weak points to drain stamina fast, and work the chain tension to haul each monster in — red tension snaps the chain. Every monster telegraphs its ability; dash through it (Shift/J) and a perfect dodge opens a counter window. Fill the bestiary in 6 nights: a salvage draft of boons between nights, an outfitter at camp, weather, and three difficulties — GENIN, SHINOBI, KAGE. Plain HTML/JS on a canvas, no build step, nothing loads over the network.

## Run it

```sh
node serve.ts
```

Then open http://127.0.0.1:8377 — serve.ts serves the `game/` folder statically. Any static file server pointed at `game/` works too.
